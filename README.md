A beautiful, fully-featured Markdown editor and live previewer built with React. Perfect for writing READMEs, documentation, or just taking notes.

## ✨ Features

- **Live Preview:** See your markdown rendered in real-time as you type
- **Syntax Highlighting:** Beautiful code blocks using Highlight.js
- **Toolbar:** Quick insert buttons for common markdown syntax
- **Theming:** 4 built-in themes (Light, Dark, Dracula, Solarized)
- **Export Options:** Export your document as HTML or PDF
- **Stats:** Live word count, character count, and read time estimation
- **Security:** Sanitized HTML output to prevent XSS attacks

## 🚀 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/RBKesh/markdown-previewer.git
   ```
2. Navigate into the directory:
   ```bash
   cd markdown-previewer
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## 💻 Usage

To start the development server, run:
```bash
npm start
```
The app will automatically open in your default browser at `http://localhost:3000`.

## 🛠️ Tech Stack

- [React 18](https://reactjs.org/)
- [Marked](https://marked.js.org/) (Markdown parsing)
- [Highlight.js](https://highlightjs.org/) (Code syntax highlighting)
- [DOMPurify](https://github.com/cure53/DOMPurify) (HTML sanitization)
- CSS3 (Variables, Flexbox)
